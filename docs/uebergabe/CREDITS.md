# Credits

## Grafik, Musik, Sound
Alle Grafiken (`src/art/`) sind eigene SVG-Zeichnungen für dieses Spiel. Musik und Soundeffekte (`src/audio/`) werden im Browser synthetisiert. Es sind keine fremden Grafik- oder Audio-Pakete enthalten.
